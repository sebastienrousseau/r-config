# Installation

Install `@sebastienrousseau/r-config` as a development dependency using your preferred package manager.

## npm

```bash
npm install --save-dev @sebastienrousseau/r-config
```

## pnpm

```bash
pnpm add -D @sebastienrousseau/r-config
```

## yarn

```bash
yarn add -D @sebastienrousseau/r-config
```

## bun

```bash
bun add -d @sebastienrousseau/r-config
```
